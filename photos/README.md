# photos/ — 放原始照片的地方

把你要放上地圖的照片（iPhone HEIC 或 JPEG）放進這個資料夾，
可以直接放，也可以用子資料夾分類（例如按街道或案例分類）。

接著執行：

```bash
pip install -r scripts/requirements.txt
python scripts/build_map.py
```

腳本會：

1. 從每張照片的 EXIF 讀出 GPS 經緯度
2. 產生縮圖到 `thumbs/`（HEIC 會自動轉成 JPEG）
3. 更新 `data/photos.json`

沒有 GPS 座標的照片會被略過，並在執行結果中列出。

## 目前的主題分類

照片已依畫面主要內容分到以下子資料夾；原始檔名與照片格式均保留：

- `01_步行與商業街`：徒步街、商業街、共享街道
- `02_住宅與生活巷弄`：住宅街、社區巷弄、安靜街道
- `03_路口與道路交通`：路口、穿越、號誌、幹道、減速與學區設施
- `04_自行車與慢行`：自行車街、自行車道、慢行系統
- `05_廣場公園與綠化`：廣場、公園、綠廊、樹蔭、花園與公共空間
- `06_人行道停車與街道界面`：人行道、停車、騎樓與街道障礙
- `07_建築歷史與街景細節`：建築立面、歷史建物與局部街景
- `08_其他非街景`：截圖、天空、無法判讀或非街道照片
- `09_其他媒體`：影片檔

建置腳本會遞迴掃描 `photos/` 子資料夾，因此分類後仍可直接執行上面的建置指令。

> 若你已在 GitHub 上啟用 `Build map` Action，只要把照片上傳到這個資料夾並 commit，
> 地圖就會自動更新，不需要在本機執行任何指令。
