# 生活街道案例地圖

把用手機拍的街道照片，依照片內建的 **GPS 經緯度** 自動標在地圖上，
建立一個可以持續累積的「生活街道案例資料庫」。

支援 iPhone 的 **HEIC** 與一般 **JPEG** 照片。

---

## 兩種使用方式

### 方式一：拖曳即看（不用安裝、隱私留在本機）

適合快速查看，照片不會離開你的電腦。

1. 用瀏覽器開啟 `index.html`
2. 把照片**拖進視窗**（或按右上角「＋ 加入照片」）
3. 有 GPS 座標的照片會立刻標在地圖上

> 這個方式加入的照片是「暫時」的，關掉網頁就消失，不會存進資料庫。

### 方式二：案例資料庫（可累積、可分享）

把照片變成永久的地圖案例，並且可以放上網路分享。

1. 把照片放進 `photos/` 資料夾（可用子資料夾分類）
2. 安裝套件：`pip install -r scripts/requirements.txt`
3. 執行：`python scripts/build_map.py`
4. 腳本會抽出座標、產生縮圖、更新 `data/photos.json`
5. 開啟 `index.html`（透過下方的本機伺服器或 GitHub Pages）就會看到所有案例

**免寫程式的做法**：本專案內建 GitHub Action（`Build map`）。
只要把照片上傳到 GitHub 上的 `photos/` 資料夾並 commit，
地圖資料就會**自動更新**，完全不需要在本機跑指令。

## 下載照片

網站上的每張照片都能下載，方便他人取用案例素材：

- **單張下載**：點地圖上的標記 → 彈出視窗裡按 **⬇ 下載**
- **批量下載**：按右上角 **⬇ 下載全部**，會把目前地圖上的所有照片打包成一個 ZIP 檔

> 下載的是網站顯示用的圖片（長邊約 1400px，畫質清晰、檔案精簡）。
> 若需要「完整原始解析度」可供下載，可再調整讓 Pages 一併發佈 `photos/` 原始檔
> （網站會變大，取捨見上面的大小說明）。

## 關於 Google 相簿

你提到打算把照片上傳到 Google 相簿——這完全可以，但要注意：

- **GPS 座標存在原始照片的 EXIF 裡**，所以請用「原始照片」（尚未被壓縮的檔案）
  來跑方式二的腳本，或用方式一直接拖曳原檔，才讀得到座標。
- Google 相簿**不適合**當作「網頁地圖直接顯示照片」的圖床——它沒有穩定的直連圖片
  網址，且 API 需要 OAuth 授權。因此建議：
  - **這個地圖**（`thumbs/` 縮圖 + `data/photos.json`）負責顯示；
  - **Google 相簿**單純當作原始照片的備份／相簿。

這樣分工最單純、也最穩定。

## 在本機預覽（方式二）

因為瀏覽器的安全限制，直接用 `file://` 開啟時無法載入 `data/photos.json`。
請在專案資料夾內啟動一個簡單的本機伺服器：

```bash
python -m http.server 8000
# 然後開啟 http://localhost:8000
```

## 放上網路（GitHub Pages）

本專案已內建自動部署（`.github/workflows/deploy-pages.yml`），且會**自動啟用 Pages**
（`enablement: true`），所以通常不需要手動設定：

1. 把變更合併／推送到 `main`
2. `Deploy to GitHub Pages` Action 會自動啟用並部署，稍等片刻就會得到公開網址
3. 之後每次 `main` 有更新（含「Build map」自動產生的照片資料）都會自動重新部署

> 若第一次自動啟用失敗（部分帳號權限限制），到 **Settings → Pages** 把 **Source**
> 手動選成 **GitHub Actions**，再重跑一次 Action 即可。

> 部署到 Pages 時只會發佈網站需要的檔案（`index.html`、`assets/`、`data/`、`thumbs/`），
> **不會**發佈 `photos/` 裡的原始大檔。

> ⚠ **隱私提醒**：GitHub Pages 是公開的，放上去的照片與座標所有人都看得到。
> 若照片涉及隱私（例如住家位置），請改用 **private repo**，或只用「方式一」在本機查看。

## 檔案結構

```
.
├── index.html              # 地圖網頁
├── assets/
│   ├── app.js              # 地圖邏輯（讀 EXIF、畫標記）
│   └── styles.css
├── photos/                 # ← 把原始照片放這裡（方式二）
├── thumbs/                 # 自動產生的縮圖
├── data/
│   └── photos.json         # 自動產生的地圖資料
├── scripts/
│   ├── build_map.py        # 抽 GPS + 產縮圖 + 生成資料
│   └── requirements.txt
└── .github/workflows/
    └── build-map.yml       # 上傳照片後自動更新地圖
```

## 常見問題

**照片沒有出現在地圖上？**
表示那張照片沒有 GPS 座標。常見原因：拍照當下沒開定位、照片被社群軟體或
轉檔工具去除了 EXIF、或截圖類的圖片。腳本執行結果會列出被略過的照片。
請到 iPhone「設定 → 隱私權與安全性 → 定位服務 → 相機」確認已開啟。

**HEIC 照片在方式一看不到縮圖？**
瀏覽器原生不支援 HEIC，本網頁會即時轉檔顯示；若轉檔失敗，座標仍會標上地圖，
只是沒有縮圖。方式二的腳本則一定會把 HEIC 轉成 JPEG。
